# 项目说明

## 一句话

在**一台工控机**上跑通「产线数据 → 边缘库 → 看板」的最小闭环，并让它在**断网、回滚、移交**三件事上不丢人。

## 为什么是这个形态

面试 JD 的四件事（React / Python / MQTT / TimescaleDB + 容器化现场部署）刚好能拼成一条链：

```
36 台驱动 @10Hz ──MQTT──> ingest ──批量写──> TimescaleDB ──WS──> 看板
                              │                                   │
                         本地 spool（断网续传）              聚合视图（长窗口）
```

不做的：多租户、权限、K8s、PLC 协议栈。理由写在 `adr/`。

## 演示脚本（B 批完成后）

1. `make up` → 打开 `http://localhost:5174`
2. 指着 Z6 说出「这台离线了，但数据没丢」
3. `make demo-offline` → 断网 60s → 曲线中间一段空白 → 恢复后自动补齐
4. `make diag` → 拿到 zip，讲「集成商不用登机器」
5. `make rollback` → 30 秒回到上一版

## 交付边界

| 有 | 没有 |
|---|---|
| 单机五容器编排 + 边缘 quadlet | K8s 清单、集群 |
| 幂等补传与水位线 | 跨机房容灾 |
| 诊断包与回滚脚本 | 灰度发布、A/B |
| 6 区 36 驱动的模拟器 | 真实 PLC / MultiControl 对接 |
