## 三、设计口径（改稿前先读）

- **颜色即语义**：绿 `#22C55E` 运行 / 黄 `#F59E0B` 积压·降速 / 红 `#EF4444` 故障 / 灰 `#64748B` 离线。数据用青 `#38BDF8`，品牌红 `#E2001A` 只给 logo 与主按钮——红不能同时表示"运行"和"故障"。
- **字号**：KPI 28 / 标题 16 / 面板标题 14 / 正文 13 / 标签 12 / 元信息 11。最小 11px，不再往下。
- **间距**：4 的倍数；页面边距 24，卡片间距 16。
- **圆角**：卡片 12 / 列表项 10 / 胶囊 14。
- **一屏一板**，板名 = `pages.poc.<路由>#<锚点>`，方便以后按路由对账。

## 四、怎么改（三步，别手拖）

```bash
# 1) 改色板或文案
$EDITOR docs/design/tokens.json
$EDITOR docs/design/gen-spec.mjs     # 文案、数据、布局都在这

# 2) 重新生成 spec + 本地目检
node docs/design/gen-spec.mjs
node docs/design/preview.mjs         # 出 docs/design/exports/*.png

# 3) 画进 Penpot（幂等：整页重画，不会重复叠板）
cd ../course-reservation && \
  PENPOT_TOKEN=$(cat ~/.config/penpot/token) \
  PENPOT_BASE=http://127.0.0.1:8081 \
  PENPOT_FILE="Interroll PoC" \
  node scripts/penpot/rpc-draw.mjs /mnt/disk1t/workspacePersonal/Interroll-poc/docs/design/screens/poc-dashboard.json
```

只改一屏加 `--only=02`（按序号或板名片段匹配）。

## 五、待确认

1. **主色**：现在数据用青、品牌红只给 CTA。要不要整体换成英特诺红主色？（换的话告警红要另找色）
2. **深浅**：现在深色（现场大屏/值班室友好）。若客户多是白天办公室，要一版浅色。
3. **指标口径**：吞吐 1,284 件/时、端到端 180ms 是编的，等 B 批跑通后替换成实测值。
