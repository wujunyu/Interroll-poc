# RB-02 回滚（骨架占位）

## 原则

1. **先止血再定位**：回滚不需要解释，解释放事后；
2. 镜像用不可变 tag（`sha-xxxx`），不用 `latest`；
3. 回滚不碰数据，只切镜像；数据问题走 `restore.sh`。

## 实测

`make rollback TAG=0.3.0` → **12 秒**完成：校验本地镜像存在 → 改 `APP_VERSION` → 重建 api/ingest/web → 轮询 `/healthz` 直到报出目标版本。

拒绝「半截回滚」：目标 tag 的镜像不在本地时直接退出，不动线上。

## 步骤

```bash
make rollback TAG=v0.1.0    # 切 tag → 重建 → 健康检查
make verify                 # 确认可用
```

## 验收

- 版本号在 `/healthz` 里可见且与 TAG 一致；
- 看板恢复出数；
- 数据集未回退（除非显式 restore）。
