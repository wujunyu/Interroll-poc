# RB-01 部署

> 目标：一台干净机器，30 分钟内起得来；构建与运行解耦（ADR-0004）。

## 前置

- [ ] Docker 已装（跑栈）；Podman 已装（构建镜像）
- [ ] 端口 1884 / 5433 / 8001 / 5174 空闲（改 `.env` 也行）
- [ ] 基础镜像就位：`python:3.12-slim`、`node:18-alpine`、`nginx:alpine`
      （离线现场用 `docker save | podman load` 搬进去）

## 离线交付（air-gap 现场）

```bash
# 交付方
make bundle                     # → dist/interroll-poc-0.3.1.tar.gz（约 660MB）

# 客户现场
tar xzf interroll-poc-0.3.1.tar.gz && cd interroll-poc-0.3.1
bash scripts/load.sh            # load 镜像 + 摘掉 podman 的 localhost/ 前缀
cp .env.example .env && vi .env # 改 DB_PASSWORD
docker compose --env-file .env -f compose/compose.yaml up -d
```

包里只有：`images.tar`（5 个镜像：3 个应用 + mosquitto + timescaledb）、`compose/compose.yaml`、
`.env.example`、`scripts/{load,rollback,diag}.sh`、两篇 runbook。

## 步骤

```bash
git clone <repo> && cd Interroll-poc
make env                       # 生成 .env，改 DB_PASSWORD
bash deploy/scripts/build-images.sh --load   # podman 构建 → 导入 docker
make config                    # 校验编排
make up                        # 起栈（mqtt/db/ingest/api/web）
docker compose --env-file .env -f deploy/compose/compose.yaml --profile demo up -d simulator
```

## 验收

| 检查 | 命令 | 期望 |
|---|---|---|
| 五个容器 | `make ps` | mqtt/db `healthy`，ingest/api/web `Up` |
| 接口 | `curl -s localhost:8001/healthz` | `ok:true`、`mqtt.connected:true` |
| 看板 | 打开 `http://<host>:5174` | 六区在线、曲线滚动 |
| 诊断包 | `make diag` | `dist/interroll-diag-<ts>.zip`，5 类文件、无明文密码 |

## 实测（2026-11-20）

- 构建：四镜像 podman 构建，ingest 2s / api 6s（有缓存时）/ web 6s
- 起栈：五个容器全部 Up，`/healthz` 报 `version=0.3.1`
- 回滚：`make rollback TAG=0.3.0` **12 秒**完成并等到版本号
- 诊断包：10KB，含 system/config/logs/mqtt-tail/db-stats
