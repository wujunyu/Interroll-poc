# RB-01 部署（骨架占位）

> 目标：集成商拿到一台干净的 Ubuntu 工控机，30 分钟内起得来。

## 前置

- [ ] Docker 或 Podman 已装
- [ ] 端口 1884 / 5433 / 8001 / 5174 空闲（改 `.env` 也行）
- [ ] 镜像已落地（离线现场用 `docker save` / `podman save` 导入）

## 步骤（B 批补齐）

```bash
git clone <repo> && cd Interroll-poc
make env            # 生成 .env，改 DB_PASSWORD
make config         # 校验
make up             # 起栈
make verify         # 验收
```

## 验收

- `make ps` 五个容器 healthy；
- 打开 `http://<host>:5174` 有曲线；
- `make diag` 能出 zip。

见 `RB-02-回滚.md`。
