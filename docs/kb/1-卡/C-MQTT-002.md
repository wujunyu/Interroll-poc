**主张**：QoS2 只保证「每一跳、每个会话内」不重复，**不保证端到端**；断线瞬间仍有在途窗口。
**原文**：C 组丢失 1 条，缺失 seq=99，正好落在断线时刻；该消息处于四段握手中间。
**边界**：结论支撑 ADR-0002 的取舍——数据面仍必须用 `drive_id + ts + seq` 做应用层幂等。
**冲突/反例**：若断线发生在两条消息之间，QoS2 可做到 0 丢 0 重。
